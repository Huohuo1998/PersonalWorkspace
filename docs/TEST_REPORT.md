## 浏览器组合场景

1. 标题单填任务、收集箱、安排今天、刷新持久化、事件无完成勾选、五导航。
2. 财务核对、资产负余额，服务器写成功但响应丢失，原幂等请求查询；金额遮蔽及刷新偏好。
3. 训练逐组保存、刷新恢复、失败保留当前输入、失败时禁用结束、重试后实际组历史。
4. 食谱→菜单→采购，采购已购不会造财务支出，菜单不会造实际用餐。
5. 320px 手机导航、无横向溢出、键盘 Tab/Escape、字号调整、axe 扫描。
6. 1440px 桌面截图与 axe 扫描。
7. 首页财务 503 单域失败，其他成功模块保持可见，原模块独立重试，不伪造零资产。
8. 两个共享会话页面修改同一训练组：冲突保留本端输入，核对后重存；被动体重/恢复隐藏，主动输入仍可见。
9. 新增账户后回到待填写记账表单；手机设置退出并撤销会话（已通过）。
