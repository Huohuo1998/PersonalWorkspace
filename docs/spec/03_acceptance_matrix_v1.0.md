# Personal Workspace｜设计验收与需求追溯矩阵 V1.0

> 状态：**预开发验收清单草案**。2026-10-12。  
> 说明：本表是未来原型评审/软件测试依据，**不代表网站已运行或以下测试已执行**。

## 1. 验收与优先级定义

- `P0`：核心用户流程、资金/历史正确性、真实记录边界、隐私与数据隔离；未通过时不得认定 MVP 可以验收。
- `P1`：重要可用性、效率和体验；正式上线前应补齐，部分可根据明确风险评估排序。
- `设计待验证`：页面和交互基线已确定，尚需完整交互样稿、设备或真实服务验证。
- 结果列在未来测试时填写：`未测 / 通过 / 失败 / 阻塞 / 不适用`。
