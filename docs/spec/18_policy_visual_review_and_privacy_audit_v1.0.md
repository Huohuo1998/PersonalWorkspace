## 2. 手机端和桌面端的图形校核

- **桌面** 1350×840：左侧一级导航、主内容区、核对卡片信息层级明晰。
- **手机** 390×844：单栏，底部导航与确认区分离；负余额核对稿已修订过底部按钮与导航重叠的问题。
- **未进行自动化视觉回归**。仅目视检查代表性画板；不将 390px 的结果泛化为所有手机尺寸。
- **未完成系统字号放大、软键盘、屏幕阅读器、焦点顺序、深色模式**。深色模式仍为 MVP 之外。

## 4. 与验收用例的初步映射

- `FIN-POL-01～03`：FIN-S01 代表性屏幕 + 负余额流程文字；余额校正/预算分离图示是局部证据。
- `FIN-POL-04～06`：FIN-S02 代表性屏幕 + 还款核对文字；后续卡消费仍需专门视觉态。
- `FIN-POL-07～09`：FIN-S03 代表性屏幕 + 退款核对文字；跨月/多次退款独立图稿缺失。
- `DIET-POL-01～03`：DIET-S01 仅嵌入不可换算提示；兼容换算应补一组完整对比图。
- `DIET-POL-04～07`：DIET-S02 代表性屏幕 + 文字分支；人工改量/减少需求/重复执行图稿缺失。
- `PRIV-POL-01～04`：PRIV-S01/S02 仅覆盖代表性被动摘要及主动输入；全页面与多账户权限检查尚无证据。

**设计审查结果：** 20 项新政策用例均具有已确认政策、页面规范和至少相关的候选视觉或文字依据；**20/20 仍待最终设计签收，20/20 软件未测**。
